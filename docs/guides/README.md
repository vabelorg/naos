# Guides

One task per page. Each assumes you know the basics of the [quickstart](../getting-started/quickstart.md); the exact rules are in the [reference](../reference/).

| Guide | For when you want to |
|---|---|
| [Writing tests](writing-tests.md) | Split tests into files, pick assertions, compare types that have no assertion, skip tests whose conditions are not met |
| [Diagnostics](diagnostics.md) | Know which iteration or which call of a helper failed, and stop a test from a helper |
| [Setup and teardown](fixtures.md) | Share preparation and clean-up between the tests of a suite |
| [Running tests](running-tests.md) | Run some tests only, and find hidden dependencies between tests |
| [CTest and CI](ctest-and-ci.md) | Run each test in its own process, in CTest, scripts and CI, and open failures in your editor |
| [Stubs](stubs.md) | Replace a function your code calls with a fake one |
| [Custom main()](custom-main.md) | Give the test executable arguments of its own |
| [C++](cpp.md) | Write the tests in C++ |
| [Shared library](shared-library.md) | Use Naos as a shared library (DLL) |
| [Troubleshooting](troubleshooting.md) | Find the cause of a problem from its symptom |
