# Security Policy

## Supported Versions

Only the latest release receives security fixes. Naos is before 1.0, so a fix goes into a new release, not into older minor versions.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

Do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/vabelorg/naos/security/advisories/new).

The maintainers reply within 7 days to confirm they received the report, and post an update on the advisory at least every 14 days until it is resolved.

- If the report is accepted, the maintainers fix it in a new release and publish the advisory, which credits the reporter unless they ask not to be named.
- If the report is declined, the maintainers explain why on the advisory and close it. The reporter is then free to discuss it in public.
