# コマンドライン

Naos でビルドした実行ファイル（以下の `prog`）は、どれも次のオプションを受け付けます。

```
prog [--naos-filter <patterns>] [--naos-shuffle] [--naos-random-seed <n>]
     [--naos-repeat <n>] [--naos-fail-fast] [--naos-quiet]
     [--naos-output <format>:<path>] [args...]
prog --naos-list
prog --help
```

オプションがなければ、すべてのテストを 1 回ずつ、1 つのプロセスの中で実行します。順番は、スイートを登録した順、スイートの中ではテストを並べた順です。

## オプション

- `--naos-filter <patterns>`: 名前 `<suite>.<test>` 全体がパターンに一致するテストだけを実行します。
  - `*` は任意の文字列（空や `.` も含む）、`?` は任意の 1 文字に一致します。
  - パターンは `:` で区切って複数書けます。
  - 最初の `-` より後ろは除外するパターンです。`-` の前が空なら、除外されなかったすべてのテストを選びます。
  - シェルが `*` を展開しないよう、パターンは引用符で囲みます。
- `--naos-list`: テストの名前を登録した順に 1 行ずつ出力し、何も実行しません。ほかのオプションに関わらず、順番を入れ替えず 1 回だけ出力します。この一覧は互換を保ちます。Naos の CMake の関数がこれを読んで、テストを CTest に登録します。
- `--naos-shuffle`: スイートの順序と、スイートの中のテストの順序を入れ替えます。スイートをまたいでは混ぜません。
  - 各回の最初に種を `RANDOM SEED: <n>` と出力するので、`--naos-random-seed` にその種を渡せば同じ順序で実行し直せます。
  - 同じ種なら、どの処理系でも同じ順序になります。
- `--naos-random-seed <n>`: `--naos-shuffle` に使う種で、1〜99999 です。0 か指定なしなら時刻から決めます。範囲外の値や数字以外は使い方エラーです。これだけでは順序は変わりません。
- `--naos-repeat <n>`: 選ばれたテストを n 回（1 以上）繰り返し実行します。不安定なテストを見つけるのに使います。終了コードは、すべての回を合わせた結果です。`--naos-shuffle` と組み合わせると、回ごとに種を 1 ずつ増やして（99999 の次は 1）順序を変えます。
- `--naos-fail-fast`: 最初に失敗したテストを teardown まで終えたところで止め、残りのテスト（`--naos-repeat` なら残りの回も）を実行しません。スキップでは止まりません。
- `--naos-quiet`: 成功したテストとスキップしたテスト、および `ITERATION:` を標準出力から省きます。失敗したテストはこれがないときと同じ形で出力し、実行の最後には集計も出します（[`--naos-quiet` のとき](output.md#--naos-quiet-のとき)）。終了コードと `--naos-output` のファイルは変わりません。
- `--naos-allow-no-assertions`: アサーションを 1 つも実行しないテストを成功にします。これがないと、そのテストは失敗します（[アサーションを実行しないテスト](control.md#アサーションを実行しないテスト)）。
- `--naos-output <format>:<path>`: 実行の結果を、実行の終わりにファイル `<path>` にも `<format>` で書きます。形式は `xml`（JUnit XML）だけです（[JUnit XML](xml.md)）。
  - 値は最初の `:` で分けるので、パスに `:` を含められます（`xml:C:\out\results.xml`）。
  - 形式やパスがないとき、未知の形式、2 回の指定は使い方エラーです。
- `--help`: 使い方を出力し、テストを実行せずに 0 で終了します。最後の行は、結果の[時間](output.md#時間)が何を測っているかを示します。`wall-clock time, from a monotonic clock`（単調時計による実時間）か、そのような時計のないシステムでは `processor time, from clock(), not wall-clock time`（`clock()` によるプロセッサ時間）です。

値を取るオプションは `--naos-filter=<value>` の形でも書けます。値が空のとき（`--naos-filter=`）と、値を取らないオプションに `=` を付けたとき（`--naos-list=1`）は使い方エラーです。

Naos のオプションはどこに置いても構いません。それ以外の引数は順番どおりに `argv` に残るので、[独自の `main()`](tests.md#独自の-main) で読めます。未知の `--naos-*` オプションと、どのテストにも一致しないフィルタは使い方エラーです。

```
$ prog --naos-filter 'parser.*-*.slow_*'
$ prog --naos-shuffle --naos-random-seed 4242 --naos-repeat 20
```

## 終了コード

```c
#define NAOS_EXIT_PASS   0
#define NAOS_EXIT_FAIL   1
#define NAOS_EXIT_USAGE  2
#define NAOS_EXIT_SKIP   77
```

| コード | 意味 |
|---|---|
| 0 | 失敗したテストがなく、実行したテストがすべてスキップでもない（テストが 1 つもない場合を含む）。または `--naos-list` か `--help` を指定した（スイートに誤りがなければ） |
| 1 | 1 つ以上のテストが失敗した（アサーションを実行しなかったテストを含む）、メモリが確保できなかった、または `--naos-output` のファイルを書けなかった |
| 2 | 使い方エラー（引数やスイートの誤り、順番を外れた呼び出し、開けない `--naos-output` のファイル） |
| 77 | 実行したテストがすべてスキップ |

`naos_run()` がこれらのどれかを返すので、`main()` からそのまま返します。77 は CTest と Automake がスキップとして扱うコードで、Naos の CMake の関数は `SKIP_RETURN_CODE 77` を付けてテストを登録します。
