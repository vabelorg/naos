# ガイド

やりたいこと別の手引きです。どれも[クイックスタート](../getting-started/quickstart.md)の内容を知っていることを前提にしています。細かい規則は[リファレンス](../reference/)にあります。

| ガイド | やりたいこと |
|---|---|
| [テストを書く](writing-tests.md) | テストをファイルに分ける、アサーションを選ぶ、アサーションのない型を比べる、条件がそろわないテストをスキップする |
| [診断](diagnostics.md) | ループの何回目か、ヘルパーのどの呼び出しで失敗したかを知る。ヘルパーからテストを止める |
| [setup と teardown](fixtures.md) | スイートのテストで準備と後片付けをまとめる |
| [テストの実行](running-tests.md) | 一部のテストだけを実行する。テストの間の隠れた依存を見つける |
| [CTest と CI](ctest-and-ci.md) | テストを 1 つずつ別のプロセスで、CTest・スクリプト・CI から実行する。失敗した行をエディタで開く |
| [スタブ](stubs.md) | テスト対象が呼ぶ関数を偽物に差し替える |
| [独自の main()](custom-main.md) | テストの実行ファイルに独自の引数を持たせる |
| [C++](cpp.md) | テストを C++ で書く |
| [共有ライブラリ](shared-library.md) | Naos を共有ライブラリ（DLL）として使う |
| [トラブルシューティング](troubleshooting.md) | 症状から原因を探す |
