# セキュリティポリシー

## 対象のバージョン

セキュリティ修正を受けるのは最新のリリースだけです。Naos は 1.0 より前なので、修正は新しいリリースに入れ、古いマイナーバージョンには入れません。

| バージョン         | 対象               |
| ------------------ | ------------------ |
| 最新のリリース     | :white_check_mark: |
| それより前のリリース | :x:                |

## 脆弱性の報告

公開の Issue は作らないでください。[GitHub の非公開の脆弱性報告](https://github.com/vabelorg/naos/security/advisories/new)で報告してください。

メンテナは 7 日以内に受け取ったことを返信し、解決するまで少なくとも 14 日ごとにアドバイザリで進み具合を伝えます。

- 報告が受け入れられた場合は、新しいリリースで修正し、アドバイザリを公開します。アドバイザリには、名前を出さないよう求められない限り、報告者を記載します。
- 報告が受け入れられなかった場合は、その理由をアドバイザリで説明して閉じます。そのあとは、報告者が公開の場で話して構いません。
